# 軍人将棋 オンライン対戦（本格ルール版）

相手とブラウザで遊べる軍人将棋です。プログラムが「審判」役をやるので、
相手の駒の正体は見えません（審判あり方式）。

## 動かし方（自分のPCで試す）

1. ターミナルでこのフォルダに移動する
2. 次のコマンドを実行する

   ```
   python3 server.py
   ```

3. ブラウザで **http://localhost:8000** を開く
4. 一人で試すときは、**別のタブ（またはウィンドウ）でもう一つ** 同じ住所を開く
   - 片方で「部屋を作る」→ あいことば4文字が出る
   - もう片方で「部屋に入る」→ そのあいことばを入力
5. 両方で駒（各23枚）を並べて「配置完了！」を押すと対戦開始

止めるときは、ターミナルで **Control + C** を押す。

## 盤

- 6列 × 9行。上下の中央★が各軍の**総司令部**。総司令部は横長に見えますが**「1マス」**で、置ける駒は1つだけです。
- 中央の行は**川（国境）**で、ここには**止まれません**。川を渡れるのは**「橋」2か所**だけ。
- 橋は**通り道**なので橋の上には止まれません。渡るときは、橋の手前のマスから川の向こう側のマスへ**一気に1歩で進みます**。
- ヒコーキだけは橋がなくても、川をどこでも飛び越えられます。

## 駒（各23枚）

- 1枚ずつ：大将・中将・少将・大佐・中佐・少佐・騎兵・スパイ・軍旗
- 2枚ずつ：大尉・中尉・少尉・地雷・工兵・タンク・ヒコーキ

## 動き

| 駒 | 動き |
|---|---|
| 将官・佐官・尉官・スパイ | 上下左右に1マス |
| 工兵 | 上下左右にどこまでも（飛び越せない・壁で止まる） |
| タンク・騎兵 | 周囲1マス、または前に2マス（間が空いているとき） |
| ヒコーキ | 縦にどこまでも（壁・駒を飛び越える）・横は1マス |
| 地雷・軍旗 | 動かない |

## 強さ（勝敗）

強い順：大将＞中将＞少将＞大佐＞中佐＞少佐＞大尉＞中尉＞少尉。同じ位は相打ち。

- **スパイ**：大将にだけ勝つ（他は負け）
- **タンク・ヒコーキ**：大佐以下に勝つ。将官（大将・中将・少将）には負ける。ヒコーキはタンクに勝つ
- **騎兵・工兵**：階級には勝てない。工兵は地雷を撤去でき、ヒコーキと共に地雷に一方的に勝つ
- **地雷**：工兵・ヒコーキ以外に勝つが、勝つと自分も消える（相打ち）
- **軍旗**：すぐ後ろに置いた味方の駒と同じ強さで戦う

## 勝ち方

1. 相手の**総司令部（★）を大将〜少佐で占領**する
2. または相手の**動ける駒を全滅**させる

## ルールを変えたいとき

`rules.py` を開くと、駒の種類・枚数・強さ・戦闘・盤の形を調整できます。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `server.py` | 審判役サーバー（部屋管理・移動と戦闘の判定・通信） |
| `rules.py` | 駒・盤・戦闘のルール（ここを直せば調整できる） |
| `public/index.html` | 画面の骨組み |
| `public/style.css` | 見た目 |
| `public/client.js` | 盤の描画・駒の操作・通信 |

## あとで相手とネット対戦するには

いまは自分のPCの中だけで動きます。相手（遠くの人）と対戦するには、
このプログラムをインターネット上に置く必要があります（無料のクラウドサービスが使えます）。
その手順は、遊べることを確認してから改めて用意します。
